# 广东工业大学《工程大数据分析与应用》学习资料

本仓库提供课程学习使用的 Jupyter Notebook、Python 脚本、教学数据和课程综合训练项目资料。

## 课程内容

- 第02讲：工程数据表达与 Python/Jupyter 预备
- 第03讲：工程数据质量与预处理
- 第04讲：置信区间与假设检验
- 第05讲：描述统计、探索分析与工程数据可视化
- 第06讲：回归分析与工程数值预测
- 第07讲：分类算法与工程风险识别
- 第08讲：决策树、集成学习与模型解释
- 课程综合训练项目：任务说明、数据字典和学生版数据

各讲资料位于 [lessons](lessons/) 文件夹，课程项目资料位于 [projects/course_project](projects/course_project/)。

**第06—08讲的 Notebook 已提供，配套数据尚未上传；相关代码需要数据后才能完整运行。**

## 下载与使用

1. 在仓库首页点击绿色的 **Code** 按钮，选择 **Download ZIP**，将压缩包下载并解压。
2. 在 `lessons/` 中找到相应讲次，保持 Notebook 和配套数据文件夹的相对位置不变。
3. 按课程环境说明安装 Python 3.12 和所需依赖；各讲目录中如有 `requirements.txt`，请同时查看。
4. 打开 JupyterLab 和相应 Notebook，先进行环境检查，再按顺序运行代码。

## 数据说明

仓库中的数据用于学习和方法练习，部分为经过整理或合成的教学数据，不应直接用于实际工程决策。分析结果需要结合数据来源、适用条件和工程背景解释。

## 学习建议

- 先理解数据字段、记录含义和工程背景，再运行代码。
- 调整分析条件后，结合结果说明变化及其含义。
- 课程综合训练项目可围绕问题定义、数据理解、分析过程和结果解释组织材料。
