# 广东工业大学《工程大数据分析与应用》学生学习代码

本仓库用于《工程大数据分析与应用》课程的课堂练习和课程综合训练项目，提供学生可直接下载使用的 Notebook、Python 脚本、教学数据和操作说明。

## 内容范围

- 第02讲：工程数据表达与 Python/Jupyter 预备
- 第03讲：工程数据质量与预处理
- 第04讲：置信区间与假设检验
- 第05讲：描述统计、探索分析与工程数据可视化
- 课程综合训练项目：任务说明、数据字典和学生版教学数据

后续讲次会在完成课堂材料审阅后继续更新。

## 使用方法

1. 下载相应讲次的完整文件夹，不要只下载 Notebook。
2. 按课程统一环境说明安装 Python 3.12 和依赖包。
3. 在讲次文件夹中启动 JupyterLab，打开学生版 Notebook。
4. 保持 Notebook 与 `data/`、`docs/`、`figures/` 等配套文件夹的相对位置不变。
5. 先运行环境自检，再按 Notebook 顺序执行代码单元。

统一依赖见根目录的 `requirements.txt`。各讲次如有额外说明，以讲次文件夹中的 README 或环境说明为准。

## 数据说明

仓库中的数据用于课堂教学和方法练习，部分为经过整理或合成的教学数据，不应直接用于实际工程决策。分析结果需要结合数据来源、适用条件和工程背景解释。

## 学习建议

- 先理解数据字段、记录粒度和工程背景，再运行代码。
- 修改分组字段、筛选条件或图表类型时，注意同步解释分析结论。
- 课程综合训练项目需要从问题定义、数据理解、分析过程和结果解释四个方面组织材料。
