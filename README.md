# 广东工业大学《工程大数据分析与应用》课程代码

本仓库提供《工程大数据分析与应用》课程的学生操作 Notebook、小型教学数据和配套说明，面向土木工程、工程管理、智能建造及相关专业本科生。

## 内容范围

- 第02讲：工程数据表达与 Python/Jupyter 预备
- 第03讲：工程数据质量与预处理
- 第04讲：置信区间与假设检验

当前仅发布第02—04讲。第00讲和第01讲以理论讲授为主，不在本仓库重复发布课件和逐字讲稿；后续讲次将在完成审阅后另行更新。

## 使用方法

1. 下载相应讲次的完整文件夹，不要只下载 Notebook。
2. 按课程统一环境说明安装 Python 3.12 和依赖包。
3. 在讲次文件夹中启动 JupyterLab，打开学生版 Notebook。
4. 保持 Notebook 与 `data/` 等配套文件夹的相对位置不变。
5. 先运行环境自检，再按 Notebook 顺序执行代码单元。

统一依赖见根目录的 `requirements.txt`。各讲次如有额外说明，以讲次文件夹中的 README 或环境说明为准。

## 数据说明

仓库中的数据用于课堂教学和方法练习，部分为经过整理或合成的教学数据，不应直接用于实际工程决策。分析结果需要结合数据来源、适用条件和工程背景解释。

## 仓库边界

本仓库只发布学生使用材料，不包含教师参考答案、教师演示 Notebook、课程 PPT、逐字讲稿和内部验收文件。
