- 数据文件：构件检查示例数据.csv
- 数据更新批次：DS-L02 v1.0
- 数据来源：教师为本课编制的示例数据

## 4. 理论概念映射

### 实体、事件与属性

- 构件实体：由component_id标识；
- 检查事件：由inspection_id标识；
- 构件属性：component_type、zone；
- 事件属性：inspection_time、recorded_at、result、severity_level、defect_count、temperature_c、inspector；
- 元数据：data_version以及本文件中的粒度、键、来源和使用说明。

### 类型的三个层面

以severity_level为例：

- 存储类型：整数；
- 概念类型：有顺序的等级；
- 分析角色：用于排序或分组；解释等级差时需要说明等级间距的定义。

以component_id为例：

- 存储类型：字符串；
- 概念类型：标识符；
- 分析角色：构件引用外键；字符串大小用于标识比较。

### 时间语义

- inspection_time是检查发生时间；
- recorded_at是系统记录时间；
- 两者字段格式相似，业务语义分别是事件发生时间和系统记录时间。

## 5. 课堂操作
