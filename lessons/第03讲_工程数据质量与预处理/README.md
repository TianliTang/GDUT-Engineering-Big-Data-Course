# 《工程大数据分析与应用》第3讲学生操作材料

## 操作目标

选择R04或R06，定位一条问题记录，写出处理动作和理由，并保存个人规则检查结果。

## 操作文件

- `M01_学生带做Notebook.ipynb`：课堂操作Notebook，不含预运行结果。
- `classroom_quality.py`：课堂质量检查函数。
- `data/M03_安装质检示例数据.csv`：原始记录。
- `data/M04_质量规则表.csv`：质量规则。
- `data/M05_类别与单位映射表.csv`：显式映射。
- `data/M06_数据字典.csv`：字段说明。
- `data/M10_处理前后质量汇总.csv`：课后比较所需数据。
- `docs/M08_课堂任务单与解释模板.md`：当堂记录模板。
- `docs/M09_课后核心任务与延伸阅读.md`：课后提交要求。

## 课堂操作

1. 从JupyterLab打开M01，依次运行到`FOCUS_RULE_ID`。
2. 选择`R04`或`R06`，运行后续单元格。
3. 选择一条问题记录，填写动作和理由。
4. 保存Notebook，并确认`outputs/M11_个人规则检查结果.csv`和`M12_规则问题数量.png`已经生成。

预期问题数：R04为16，R06为5。数量不一致时，先Restart Kernel and Run All Cells，再检查文件夹相对位置。

DS-C03为教学合成数据。规则阈值只用于练习，不能替代真实工程验收文件。
