# DS-C03学生数据卡

- 数据集：DS-C03 v1.1.0，教学合成数据，数据家族VEP-01。
- 场景：完全虚构的装配式公共建筑构件安装质检记录，不对应真实项目、企业或个人。
- 主表：`data/M03_安装质检示例数据.csv`，每行是一条发布质检记录。
- 业务键候选：`component_id + inspection_round`；发布标识与业务事件不能混为一谈。
- 配套输入：`data/M04_质量规则表.csv`提供R01—R11教学规则，`data/M05_类别与单位映射表.csv`提供公开的确定性映射。
- 教学任务：识别缺失、重复、时间、单位、类别与测量问题，保留处理依据并形成可复核日志。
- 边界：规则阈值只用于教学练习，不能替代真实工程验收文件；本数据不用于行业统计或预测模型评价。
