# M03｜DS-L04数据说明卡

| 项目 | 内容 |
|---|---|
| 数据名称 | 装配式墙板安装用时抽样教学数据 |
| 数据属性 | 教学合成数据 |
| 记录数 | 25 |
| 观测单位 | 一次装配式墙板安装事件 |
| 核心变量 | `installation_time_min`，分钟 |
| 样本设计 | 课堂设定为从相同施工条件和组织方案下的可比事件中抽取 |
| 固定统计量 | 均值47.0分钟，样本标准差5.0分钟 |
| 比较基准 | 总体平均用时50分钟 |
| 工程关注阈值 | 相对基准平均节省4分钟 |

本数据用于理解抽样波动、置信区间和单样本双侧t检验。课堂将记录视为独立、可比样本。工程关注阈值由教学情境给定。
