# M04｜公式与判读卡

## 对象

- 总体参数：`μ、σ`
- 样本统计量：`x̄、s`
- 标准误：`SE=s/√n`

## 均值95% t置信区间

`x̄ ± t_(0.975,n-1) × s/√n`

主案例：`47 ± 2.064×1 = [44.936,49.064]`分钟。

## 单样本双侧t检验

- `H0: μ=50`
- `H1: μ≠50`
- `t=(x̄-50)/(s/√n)`
- 主案例：`t=-3.0，df=24，p≈0.0062`

## 四句式结论

1. 样本差值；
2. 95%置信区间；
3. p值、显著性水平和统计决定；
4. 工程阈值、适用范围和下一步行动。
