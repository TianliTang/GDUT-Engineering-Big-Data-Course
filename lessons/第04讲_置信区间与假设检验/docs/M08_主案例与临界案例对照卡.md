| 证据 | 主案例A | 临界案例B |
|---|---:|---:|
| `n` | 25 | 25 |
| `x̄` | 47.000 | 48.000 |
| `s` | 5.000 | 5.000 |
| 95%CI（总体均值） | [44.936, 49.064] | [45.936, 50.064] |
| `t` | -3.000 | -2.000 |
| 双侧`p` | 0.0062 | 0.0569 |
