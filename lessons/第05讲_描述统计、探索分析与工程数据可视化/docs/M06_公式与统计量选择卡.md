# M06｜公式与统计量选择卡

## 中心

- 算术均值：`x̄=Σxᵢ/n`
- 加权均值：`x̄w=Σwᵢxᵢ/Σwᵢ`
- 中位数：排序后的中间位置
- 众数：出现频数最多的值或类别

## 离散

- `IQR=Q3-Q1`
- 完整有限总体：`σ²=Σ(xᵢ-μ)²/N`
- 更大总体的样本：`s²=Σ(xᵢ-x̄)²/(n-1)`
- 变异系数：`CV=s/x̄`，只用于有真实零点且均值远离0的变量

## 关系

- 协方差符号表示共同偏离方向，数值大小受单位影响
- Pearson `r`概括线性关系
- Spearman `ρs`概括秩次的单调关系
- 相关报告同时包含有效N、散点形态和分组检查

## 选择

- 近似对称：均值＋标准差
- 偏态或含合理极端值：中位数＋IQR，并保留均值作对照
- 类别变量：频数＋比例＋众数
