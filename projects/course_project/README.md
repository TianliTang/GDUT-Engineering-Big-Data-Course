# 课程综合训练项目学生材料

本目录为《工程大数据分析与应用》课程综合训练项目的学生发布材料。

学生需要先阅读`课程项目任务书_学生版.md`，再从两个数据包中任选一套，并在该数据包给出的业务情境中选择一个问题开展分析。

## 目录说明

- `课程项目任务书_学生版.md`：统一项目任务、分析要求和提交物说明。
- `学生发布版_课程项目介绍/`：学生版项目说明文档。
- `01_城市更新回迁安置方案比选/`：数据包A，包含任务书、数据说明、字典、质量报告、校验文件和`data.zip`。
- `02_存量公共建筑绿色改造投资组合/`：数据包B，包含任务书、数据说明、字典、质量报告、校验文件和`data.zip`。

## 数据使用

每个数据包中的原始CSV放在`data.zip`内。下载后先解压，再按`data_dictionary.csv`和`data_card.md`理解表结构、字段含义和数据粒度。`checksums.sha256`用于核对解压后的CSV是否与发布版本一致。

数据为教学合成数据，仅用于课程训练，不能用于现实项目判断或行业统计。
